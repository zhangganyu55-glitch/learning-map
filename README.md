# 学习地图

一个单文件网页软件：**打开就是日历**，点某一天，才看到那天要做什么。没有周数、没有截止日期，日历能一直往后翻。双击 `index.html` 就能用，不用装东西、不用联网。

## 怎么用

**打开**：双击 `index.html`。

**每天**：打开 → 今天是哪一格（有浅沙底色）→ 点它 → 下面就是今天要做的事 → 做一件勾一件 → 卡住的地方写在「今天的卡点」里。右上角那个小圆点按钮随时把你送回今天。

| 想做的事 | 怎么做 |
| --- | --- |
| 看某天要做什么 | 点日历上那一天，下面会跟着换 |
| 勾掉一项 | 点行首的圆圈 |
| 改文字 | 双击任务文字（手机上点一下） |
| 加一件事 | 点「＋ 加一件事」，打字回车 |
| 换到别的日子 | 行右侧 `→`，选新日期 |
| 调整同一天里的顺序 | 行右侧 `↑` `↓` |
| 删掉一项 | 行右侧 `✕`，删错了 6 秒内能点「撤销」 |
| 翻月份 | 右上角 `‹` `›` |

## 数据存在哪

存在浏览器的本地存储里（键名 `learning-map-state-v2`），只在这台电脑、这个浏览器里，不上传任何地方。关掉再打开、刷新，勾选和卡点都还在。

会丢数据的只有一种情况：清理浏览器缓存时把"网站数据"一起清了。所以每周日收工时点一下**「导出备份」**，会下载一个 `学习地图-备份-日期.json`；要恢复就点「导入备份」。导出的文件可以丢网盘或 git 仓库，那就是你真正的学习记录。

注意：备份格式在改成日历版时换过一次（旧的周制备份键名是 `learning-map-state-v1`）。导入旧备份会提示格式已变，不会静默出错。

## 已知限制

- 只做了浅暖色这一套配色，没有深色模式。
- 任务不能设置重复（比如"每天背 20 个单词"要手动加）。
- 没有提醒推送、没有云同步。多设备之间靠导出/导入 JSON 搬。
- 手机上是能看能用的（375px 宽度验证过不跑版），但交互是按电脑设计的。
