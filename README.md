# 学习地图

一个单文件网页软件，把《五个月行动计划》那 19 周摊成一张可勾选、可自己改的进度地图。双击 `index.html` 就能用，不用装东西、不用联网。

## 怎么用

**打开**：双击 `index.html`。（想放到启动台或 Dock，右键保留即可；也可以拖进浏览器书签。）

**每天**：打开 → 看第一张展开的卡（那是"你现在该做的"）→ 做一项勾一项 → 卡住的地方写进最下面的「卡点记录」。

| 想做的事 | 怎么做 |
| --- | --- |
| 勾掉一项 | 点左边的方框 |
| 改文字 | 双击任务文字或周标题（手机上点一下） |
| 调整顺序 | 鼠标移到任务上，点右边的 ↑ ↓ |
| 删掉一项 | 点右边的 ✕，删错了 6 秒内能点提示里的「撤销」 |
| 加自己的任务 | 每周最下面那个输入框，打完回车 |
| 加一整周 | 上方「＋ 加一周」，或列表最底下那个按钮 |
| 看某周的进度 | 点顶栏那 19 个小格子，会跳到对应的一周 |

## 数据存在哪

存在浏览器的本地存储里（键名 `learning-map-state-v1`），只在这台电脑、这个浏览器里，不上传任何地方。关掉再打开、刷新，进度都还在。

**两个会丢数据的操作**，提前知道一下：

- 清理浏览器缓存 / "清除网站数据"时勾了这个页面，进度会被清掉。
- 换电脑、换浏览器不会自动同步。

所以每周日收工时点一下**「导出备份」**，会下载一个 `学习地图-备份-日期.json` 到「下载」里。要恢复就点「导入备份」选那个文件。导出过的文件可以丢进网盘或 git 仓库，那就是你真正的学习记录。


界面冒烟测试（真开浏览器跑一遍勾选、增删、刷新、重置）：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
  --no-first-run --allow-file-access-from-files --virtual-time-budget=12000 --dump-dom \
  "file:///Users/gebilaozhang/Documents/Codex/我的项目/学习地图/tests/ui-smoke.html" \
  | sed -n '/<pre id="out">/,/<\/pre>/p' | sed 's/<[^>]*>//g'
```

结尾出现 `TOTAL n/n` 且没有 `FAIL` 行就是通过。

结构：`index.html` 里 `/* ===== CORE ===== */` 到 `/* ===== CORE END ===== */` 之间是纯逻辑（不碰 DOM），单元测试就是把它抽出来跑的；之后是同文件里的界面层。

设计稿与实施计划在 `docs/superpowers/` 下。
